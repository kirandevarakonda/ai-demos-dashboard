## 🚀 Quick Start (5 Minutes)

### 1. Install
```bash
cd content-generator/backend
pip install -r requirements.txt
npm install
```

### 2. Configure
```bash
# Create backend/.env
echo "OPENAI_API_KEY=sk-your-key-here" > backend/.env
```

### 3. Run
```bash
# Terminal 1: Backend
cd backend && node server.js

# Terminal 2: Frontend
cd content-generator && npm run dev
```

### 4. Test
```bash
./test_enhanced.sh
```

### 5. View Metrics
```bash
curl http://localhost:3001/api/metrics
```

## 📊 API Endpoints

### Content Generation (Enhanced)
```bash
POST /api/keywords    # Generate keywords
POST /api/titles      # Generate titles  
POST /api/topics      # Generate topics
POST /api/content     # Generate content

# All support: { "input": "...", "useDspy": true/false }
```

### MLOps Monitoring (New)
```bash
GET /api/metrics              # Overall system metrics
GET /api/metrics/comparison   # DSPy vs manual prompts
GET /api/metrics/history      # Historical data (24h)
GET /health                   # Health check
```
